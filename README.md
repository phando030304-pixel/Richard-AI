# 🤖 Richard AI

Richard AI is an AI-powered interactive portfolio that allows visitors to learn about me through conversation.

Instead of browsing a traditional portfolio, users can ask Richard AI about my education, experience, projects, skills, interests, and career goals.

## 🌐 Live Demo

[Try Richard AI](https://richard-ai-flame.vercel.app/)

## ✨ Features

- Interactive AI chatbot
- Personalized knowledge base
- Information about my education, experience, projects, and interests
- Responsive web interface
- Server-side API integration

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Google Gemini API
- Google GenAI SDK
- Git & GitHub
- Vercel
